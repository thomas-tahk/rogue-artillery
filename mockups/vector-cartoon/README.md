# vector-cartoon

Bold vector cartoon: saturated colours, thick navy outlines, chunky toy tanks, layered hills, grassy-lip terrain over dirt bands, chunky rounded HUD panels.

- Pack vs code: nothing from a pack (Kenney download blocked, 403). Everything is code-drawn: sky gradient, clouds, hills, terrain, tanks, explosion, HUD.
- Final art would need: proper vector tank sprites (several types, animated barrel/wheels), a textured terrain shader with grass/dirt tiles, particle sprites for smoke/debris, a rounded display font, UI 9-slice panels.

Palette: ink #1d2540, sky #2b8ff0 to #c4f0ff, grass #62d43c / #9cf06a, dirt #d98b45 #b86a36 #93502d #6f3a26, player blue #2e8cff, enemy red #ff5a4d, accent yellow #ffe36b, shell gold #ffcf33, panel navy #27335c, banner orange #ffb524, wind cyan #5fd0ff.

Capture: `godot --path mockups/vector-cartoon --resolution 1280x720 --position 3000,3000 -- --capture`

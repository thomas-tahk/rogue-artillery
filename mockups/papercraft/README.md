# Papercraft diorama

Palette: cream #fbf1dc, ink #3b2a20, grass #5aa845 / #3f8a3a, soil #a05f3a / #7a4429, player teal #1f93a8 / #12687a, enemy red #e0472f / #a82c1e, mustard #f4b632, orange #f08a2e, hills #e9a38f #c97e7a #9c6a76.

- Idea: everything is layered cut paper on a tabletop; depth comes from stacked soft drop shadows and pale cut edges, grain from a noise shader.
- Pack vs code: 100% code (jittered polygons, shadows, confetti, starburst, noise overlay). No packs. Font is a local system stand-in, not bundled.
- Final art would need: real paper/card textures, hand-cut sprite variants per unit, animated paper-fold explosion frames, a CC0/licensed handwriting font, terrain redraw with destruction-aware layered shadows.

Capture: `godot --path mockups/papercraft --resolution 1280x720 --position 3000,3000 -- --capture`

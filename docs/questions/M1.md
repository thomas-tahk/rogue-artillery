# M1 — choices made without asking (say so only if you disagree)

Defaults picked so the build never waited on you. Each is easy to change.

## Shape / scope
- **Next milestone = one real battle** (you vs one AI tank, turns, damage, win/lose, restart). Smallest step from "one tank shoots dirt" to "a game".
- **Power is set with keys (W/S), not a hold-and-release bar.** GDD says "no timing-based power mechanic"; this keeps power as a choice, not a reflex. Alternative: fixed power per shot type (angle alone sets range).
- **Controls:** ←/→ drive · ↑/↓ angle · W/S power · Space fire · R new battle. GDD's mouse click-drag aiming deferred to M2.
- **Move-then-shoot turns** (classic). The "discrete action per turn" research question (docs/TODO_research.md) deferred to M3.
- **Wind** re-rolls every turn, −10..10, shown in the HUD. GDD allows wind; per-biome weather comes later.
- **Static camera framing the whole map** (DevNotes pending decision "static vs follow"). Follow-cam deferred to M2.
- **Tiles stay** (16 px) for terrain; pixel-bitmap terrain deferred to M5 behind the same `Terrain` API.
- **Falling off the map = death** (GDD ring-out win condition). No fall damage yet.
- **Both tanks die on the same shot = You Lose.**
- **Enemy AI** computes a real shot then misses by up to ~60 px at random. Gets you in 2–4 hits.

## Tech
- **Placeholder-art branch merged into M1** (your coloured sprites, commit e3e1862) — it had no PR.
- **Renderer switched Mobile → Compatibility.** Required for the Web build; 2D game loses nothing.
- **Shells are deterministic (scripted flight), not RigidBody.** Lets the AI predict exactly where a shot lands and makes tests repeatable.
- **Old prototype scripts removed** (gun.gd, angle_indicator_ui.gd, terrain_destroyer.gd, bullets.*, shooter.tscn) — replaced by tank/projectile/terrain/battle.
- **Web build hosted on GitHub Pages** from a `gh-pages` branch, one folder per branch. Needs Pages switched on once (PR has the steps).
- **Tests** are a tiny home-made headless runner (tests/run.sh), no add-on (GUT) download.
